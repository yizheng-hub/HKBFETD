# Frozen original classification method

This directory is an immutable snapshot of the classification implementation
from Git commit `de8b46b32fb5853a0777cacd09cbe099b4141a08`.

The corrected V2 replay verifies every file against
`source_manifest.json` before importing it. Do not edit these files in place.
Physical-attribute repairs are supplied through the replay adapter; web-derived
function evidence and later rule/model changes are deliberately excluded. The
frozen Step 10 code and mapping remain part of the method because raw Step 9
labels are not the original public classification contract.
